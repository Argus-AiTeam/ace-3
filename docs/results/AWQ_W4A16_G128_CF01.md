# ACE-3 MP AWQ W4A16 G128 milestone

`START_ACE3_MP_AWQ_ADAPTATION` is implemented here as one reusable,
synthesizable G128 dot lane for one logical native-AWQ output. The exact
signed 96-bit Q47.48 accumulator rounds once to binary16 with
round-to-nearest-ties-to-even, gradual subnormals, canonical positive zero,
and finite overflow saturation.

## Reproduction

The source and contracts promoted into this repository are byte-identical to
the accepted CF01 inputs listed below. The original evidence was reproduced in
the isolated ACE-2-side development workspace with:

```sh
make
```

That historical command checked the two-profile contract, verified the
accepted evidence and official tensor hashes, regenerated vectors with seed
`0xace3cf01`, ran the integer-only oracle, ran Icarus and Verilator
simulations, and compared pre/post inventories of the ACE-2 `rtl/**` and
`verification/**` files. The standalone ACE-3 build wrapper and additional
X/Z/property coverage are tracked separately; this promotion does not claim
that those checks have already run from this repository layout.

## Final result

- Icarus Verilog 11.0:
  `AWQ_W4A16_G128_PASS cases=30 pairs=3840 ulp_bound=0 reset=pass clear=pass backpressure=pass`
- Verilator 4.038:
  `AWQ_W4A16_G128_VERILATOR_PASS cases=30 pairs=3840 ulp_bound=0 reset=pass backpressure=pass`
- Vectors: 10 official layer-0 `q_proj` tensor cases and 20
  contract-valid directed cases. Coverage includes every native reorder
  nibble, no-plus-one zero-point subtraction, signs, normal/subnormal/zero,
  ties-to-even, positive/negative saturation, non-finite flagging, reset,
  synchronous clear, input stalls, and stable output backpressure.
- Agreement: exact accumulator bits and zero-ULP binary16 agreement for all
  30 cases.
- Preservation: all 578 pre-existing files under `rtl/**` and
  `verification/**` matched their before hashes after verification.

Final attempt: `attempt-0004/`. Earlier numbered attempts are retained:
0001 records unsupported tool options and the first elaboration failure;
0002 records the repaired Icarus pass and Verilator path failure; 0003 records
the dual-simulator pass before width-warning cleanup.

## Remaining scope

This result is not a complete projection or decoder. Remaining work includes
the other G128 groups and output lanes, projection reduction/scheduling,
RMSNorm, RoPE, attention score/value flow, softmax, KV cache, and `lm_head`.
No synthesis, timing, area, power, PPA, FPGA, full-model, chip, or Stage-1
claim is made.
