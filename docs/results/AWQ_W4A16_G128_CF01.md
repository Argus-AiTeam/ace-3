# ACE-3 MP AWQ W4A16 G128 milestone

`START_ACE3_MP_AWQ_ADAPTATION` is implemented here as one reusable,
synthesizable G128 dot lane for one logical native-AWQ output. The exact
signed 96-bit Q47.48 accumulator rounds once to binary16 with
round-to-nearest-ties-to-even, gradual subnormals, canonical positive zero,
and finite overflow saturation.

## Standalone hardening result

Validated from the repository root on 2026-08-24 with Python 3.13.5, GNU Make
4.3, Icarus Verilog 11.0, and Verilator 4.038:

```sh
make clean
make OFFICIAL_TENSOR_DIR=/path/to/official_tensors test
printf 'corrupt\n' >> build/vectors/pairs.hex
make OFFICIAL_TENSOR_DIR=/path/to/official_tensors test
```

The final command is intentionally a second non-clean invocation after
corrupting the ignored live `pairs.hex`. It removes and regenerates the vector
directory, restores the bound hash, reruns authentication and tamper rejection,
and visibly repeats both Icarus compilations/simulations and the Verilator
build/simulation rather than reusing semantic pass stamps.
The injected corruption had SHA256
`2644d7f9301f9f45b37d02b5aa26abfad7bd5eac1a66fb98157002de6075d5a0`;
the second invocation restored
`9253b5ee7dc4ed7f9df131def3a2dd0ccd6adca477d2e4848166d8029dfde5e3`.

## Remaining scope

This historical CF01 result is not itself a complete projection or decoder.
The additive full-input projection milestone is documented separately in
`AWQ_W4A16_PROJECTION_CF02.md`; it does not alter the hashes or claims above.
RMSNorm, RoPE, attention score/value flow, softmax, KV cache, and `lm_head`
remain outside both milestones. No synthesis, timing, area, power, PPA, FPGA,
full-model, chip, or Stage-1 claim is made.
