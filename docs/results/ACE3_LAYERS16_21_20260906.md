## Layer21: what changed, and what did not

Attempt001 fails its original independent PyTorch CPU float64, unrounded-
interstage policy at token 0 / hidden 62: RTL `100.0` versus reference
`100.4875845949573`, absolute error `0.48758459495729767`, relative error
`0.004852187431140282`, distance `8` ULP. It remains **FAIL**.

Attempt002 aligns the independent reference with **round-to-nearest-even FP16
at each implemented interstage boundary**. This changes the reference policy,
**not RTL arithmetic**, and does not establish unrestricted float64 equivalence.
Under the aligned policy it has zero failing coordinates, maximum absolute error
`0.015625`, and final token 0 / hidden 62 equal to `100.0` on both sides.

The unchanged acceptance formula is:

```text
abs_error = abs(produced - reference)
relative_error = abs_error / max(abs(reference), 2^-14)
accept = (abs_error <= 0.125)
         OR ((relative_error < 0.001) AND (ULP_distance <= 1))
```

ULP distance uses ordered FP16 encodings of the produced value and the
round-to-nearest-even FP16 reference. Values must be finite. **This is not a
uniform ≤1-ULP guarantee**: the absolute branch can accept larger ULP distances.
Attempt002's observed maximum is **1,687 ULP** and maximum relative error is
`0.8814002089864159`; those coordinates still satisfy the absolute branch.
Likewise, older PASS maxima above `0.125` are possible through the combined
relative/ULP branch.

Attempt002 nevertheless used **fresh vectors, a fresh Verilator compile and a
fresh RTL process**, not a relabelled execution. Its trace and final bytes are

## Audit commands and reproducibility boundary

The summary preserves each attempt's actual compile/simulator arguments with
`$ATTEMPT` substituted for its private absolute directory. For example, the
recorded layer21 commands are equivalent to:

```sh
# Historical commands only: NEVER rerun into the immutable original attempt.

make --no-print-directory model24-rtl-layer-compile \
  MODEL24_RTL_LAYER_INDEX=21 MODEL24_RTL_ACCURATE_SILU=1 \
  MODEL24_RTL_CASCADE_DIR="$ATTEMPT"

  --layer-index 21 --vector-dir "$ATTEMPT/vectors" \
  --raw-dir "$ATTEMPT/raw" --progress-interval 1000000
python3 -B "$ATTEMPT/compare_fp16_policy.py" --attempt-dir "$ATTEMPT"
```

Vector generation was an in-process call to
`model24_execution_oracle.materialize_indexed_decoder_vectors`, authenticated
against the checkpoint, tensor map, complete predecessor SHA256, numeric layer
index, and `accurate_silu=True`; its harness and boundary manifest are hash-pinned.
The recorded toolchain includes Python 3.13.5, Verilator 4.038
(`v4.036-114-g0cd4a57ad`), GNU Make 4.3, and GCC 11.4.0.

For an archive holder, this read-only standard-library check validates the
published receipt hashes and independently checks every original seal entry.
Set `$ARCHIVE_BUILD` to the directory containing the original attempt folders
and `$FROZEN_R20_SOURCE` to the authenticated frozen source. Run from this
repository; **nothing is rebuilt, executed from the archive, or rewritten**:

```sh
python3 -B - "$ARCHIVE_BUILD" "$FROZEN_R20_SOURCE" <<'PY'
import hashlib, json, sys
from pathlib import Path
summary = json.loads(Path("docs/results/ACE3_LAYERS16_21_20260906.json").read_text())
build, source = map(Path, sys.argv[1:])
def sha(path):
    with path.open("rb") as stream:
        return hashlib.file_digest(stream, "sha256").hexdigest()
for attempt in summary["attempts"]:
    root = build / attempt["id"]
    for receipt in attempt["artifact_receipts"] + list(attempt["outputs"].values()):
        path = root / receipt["path"]
        assert sha(path) == receipt["sha256"]
        assert path.stat().st_size == receipt["bytes"]
    seal = json.loads((root / "sealed_output_manifest.json").read_text())
    differences = []
    for entry in seal["artifacts"]:
        path = root / entry["relative_path"]
        if sha(path) != entry["sha256"] or path.stat().st_size != entry["bytes"]:
            differences.append(entry["relative_path"])
    assert differences == [item["path"] for item in attempt["seal"]["discrepancies"]]
    print(attempt["id"], "original_status=" + attempt["status"],
          "seal_discrepancies=" + repr(differences))
for relative, expected in summary["frozen_r20_source"]["files_sha256"].items():
    assert sha(source / relative) == expected
print("Published receipts verified; documented layer19 seal exception remains.")
PY
```

This verifies the receipts, **not numerical recomputation**. A reader without
the retained private archives cannot reproduce these simulations from this
documentation alone. Runtime source/dependency closure and a clean reproducible
release remain separate work.
