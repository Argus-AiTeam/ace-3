# ACE-3: bounded Q-projection single-round RTL milestone

**COMPONENT IMPLEMENTATION / LOCAL ICARUS RTL SIMULATION**

Date: 2026-09-06. The frozen Q-projection component was compiled with
**Icarus Verilog** and simulated with **vvp**. All **29** observed Q outputs,
flags, and pre-bias accumulators matched their per-case arithmetic expectations.
This is actual integer/fixed-point RTL arithmetic, not software-produced
expected Q values injected as DUT outputs.

The [compact summary](ACE3_Q_PROJECTION_RTL_20260906.json) records selected
positive facts, coverage, artifact identities, and the integration boundary.

## Implemented arithmetic boundary

The tested frozen shared projection engine has an optional
`SINGLE_ROUND_BIAS` mode. It adds bias to the **exact fixed-point accumulator
before one FP16 round-to-nearest-even conversion**, while preserving the
observable **pre-bias accumulator** contract.

The tested QKV cluster explicitly selects this mode for Q. Legacy behavior
remains the compatible default; the new mode is opt-in. The arithmetic profile
is native asymmetric AWQ W4A16, **group size 128**, FP16 activations, and
**no qzero plus-one adjustment**.

These statements describe the **frozen component implementation that was
tested**, not a new runtime-source release in this public update.

## Bounded coverage and result

| Case group | Coverage |
| --- | --- |
| Official model-bound fixture | 16 authenticated layer0, zero-based position2 Q-output channels, covering all packed nibble lanes plus selected channels |
| Directed arithmetic/handling | 13 cases covering rounding ties, cross-group cancellation, underflow, overflow, zero, bias ordering, and nonfinite-input handling |
| Compiled result | All 29 Q outputs, flags, and pre-bias accumulators agree with their per-case expected behavior |

The official channels are `0-7, 85, 95, 126, 137, 201, 207, 292, 392`.
This is **16 selected channels, not RTL coverage of all 896 Q channels**.
One recorded official result is channel **85**: FP16 bits **`0xc795`**,
value **`-7.58203125`**.

Before selecting the frozen vectors, a pre-existing independent binary64
dot-plus-bias software candidate was compared with an integer exact-accumulator
oracle. Finite arithmetic comparisons and directed handling expectations are
kept distinct. In particular, overflow/nonfinite cases test **handling
semantics**; they are not accepted finite model outputs.

and still needs wiring to select the new mode. Full-model integration,
actual-output-fed traversal, a compatible K/V seed, and dialogue remain
**pending**. This component result does not mean full-model Q is fixed,
all 24 layers are verified, or continuous generation has started.
